# 很酷TV (v6.3.0)

基于 Tauri 2、Rust 与 FFmpeg 构建的 macOS 本地与网络媒体播放应用，采用全键盘/遥控器焦点导航，支持本地影视管理、IPTV 直播、抖音与 bilibili 短视频浏览、米家智能家居环境感知及实时气象提示。

---

## 功能概览

- **品牌开机动画、跨屏自适应缩放、Apple tvOS 全屏模糊材质与多风格联名交互音效**：启动时展示精致优雅比例的 Fire TV 风格 **“很酷TV”** 专用字体品牌标识与流光掠影开机动画（以 `2000×1125` 2K 显示器视觉比例为基准，在 `1280×720` HiDPI 43 英寸大屏等不同系统分辨率下自动等比适配，并在退场阶段以平滑阻尼曲线执行黑色遮罩渐变淡出 + 光影图案与 **“很酷TV”** 文字同步轻微放大消失效果过渡至主界面）；默认采用顶部侧边栏布局（支持切换顶部与精致微缩版左侧边栏），提供 Liquid Glass（深色/浅色）与传统毛玻璃材质选项；全屏对话框（设置页、密码页、电源选项页、恢复出厂设置确认页、关机页）采用 **Apple tvOS 原生全屏材质设计**（`blur(118px) saturate(22%)` 超大半径模糊与色度抑制 + 亮暗部主色调自适应提取映射 + TPDF 蓝噪声防色带抖动层），滤除底层杂乱色彩的同时自然透出底层亮部与暗部的明暗呼吸感与主色调；内置具备 `AudioContext` 缓存同步重建与 `AVFoundation` 48kHz PCM WAV/MP3 `Blob` 多声道 `HTMLAudioElement` 双引擎持久化的无损交互音效系统，提供 **“Fire TV 原生”**（默认）、**小狗品牌联名音效方案 “poopoozoo”**（方向键与返回键触发 `poopoo` 音效，回车确认键触发 `zoo` 音效）、**“深海流光”** 与 **“星云潮汐”** 四套方案，并配备优化后的 `20%`–`100%` 对数感知音量曲线及独立的气象信息 Fire TV 提醒音效。
- **开始页（用户头像家庭与气象感知页）**：当焦点位于侧边栏用户头像时进入**开始页**，大小标题排版与其他导航项保持一致且同样具备微透明质感，大标题显示 **`用户名，问候语`**（如“高博，晚上好”），下方避免使用粗体，善用内联 SVG 图标（房屋、定位针、温度计、水滴、预警三角）并以有温度的精炼陈述句直接呈现家庭名称（如“高博的家”）、米家实时温湿度、当前城市及实时温湿度与气象预警（如有），温度与湿度之间不设分隔符。
- **全场景微透明焦点引导与“连贯不打断”导航体验**：当焦点位于侧边栏导航项（含开始页）时，标题、丸形菜单、开始页看板与卡片统一应用微透明效果；当焦点移至丸形菜单项时，标题和丸形菜单恢复不透明，卡片保持半透明效果；当焦点位于某个媒体卡片时，其余非选中卡片应用微透明效果；当板块大标题为“暂无视频内容”状态时，自动隐藏小标题与副标题；当焦点从卡片或丸形菜单返回侧边栏当前导航项、或从设置页返回主页面时，焦点自然落在对应导航项/设置按钮上，页面布局与进入前保持一致，背景视频绝不被打断；从预览画面进入正式播放页面时 100% 复用当前活动播放流，杜绝打断重播。
- **正在观看**：按“很酷 TV+”、“有线电视”、“短视频”（及解锁后的“限制级”）分区记录播放历史，各分区独立保存最多 20 条记录，支持断点续播与同剧集多集自动归并；短视频内容（含从“正在观看”进入后开启“只看作者”加载的后续作品）大标题始终显示“作者名 + 的视频”，副标题显示“短视频社区 · 媒体源”。
- **很酷 TV+**：支持剧集与电影双目录扫描，大标题统一显示“很酷 TV+”品牌标识，自动解析季/集编号，抓取并本地缓存 TMDB 元数据、海报、透明 Logo 及豆瓣/TMDB 评分；剧集正式播放页面支持底部无遮挡选集列表切换。
- **有线电视**：支持 M3U/IPTV 直播源播放、境内/海外源分流、隔行扫描反交错处理及 XMLTV EPG 节目单匹配。
- **短视频**：聚合抖音与 bilibili 多分类视频流，一级丸形菜单默认显示当前对应子分类名（如“抖音精选”、“bilibili 推荐”），二级丸形菜单首项内置等高 Liquid Glass 搜索框（实时过滤标点符号，返回键专注退格不失焦，通过方向键移出搜索框）；左侧状态指示器支持 **“正在刷新”**（旋转箭头动画 + “正在刷新”）、**“正在搜索”**（忽明忽暗放大镜动画 + “正在搜索”，搜索补位卡片同步采用忽明忽暗放大镜符号）与 **“完成”**（自动隐藏）三种状态；支持正式播放页面长按确认键（`Return`）倍速快进、松手释放恢复正常速度，以及“只看作者”多页作品连播模式。
- **通用设置、列表化系统信息页与恢复出厂设置全屏确认页**：多级全屏设置页包含 **“通用设置”** 与 **“个性化设置”**（长按可显现“限制级内容设置”）；“通用设置 -> 系统信息”采用与普通设置页面完全一致的列表项布局，依次排列系统名称（**`很酷自在OS 6`**）、系统版本号（**`6.3.0.1020`**）、macOS 版本、本机 IP 地址、本机 MAC 地址、设备实时内存、CPU 占用，最后一项为 **“恢复出厂设置”**（点击后进入全屏确认对话框，提醒将清除缓存数据、流媒体账户和本地设置，确认按钮先置灰倒计时 5 秒后启用触发）。
- **遥控器音量键直通与 macOS 权限持久化**：严格放行与本应用操作无关的系统功能键（`F1`–`F15`）及媒体音量键，并为蓝牙遥控器映射的 `F11`（`key_code=103` 音量减）/ `F12`（`key_code=111` 音量加）提供系统音量桥接调节；应用包内置完整 macOS TCC 权限说明并采用固定 Bundle Identifier（`com.gaobo.cooltv-mac`）与 `designated => identifier "com.gaobo.cooltv-mac"` 签名规范及包外运行时状态隔离，实现可移除宗卷与本地网络一次性授权后跨版本更新持久有效。

## 运行与开发

### 直接运行
项目根目录包含已打包的 `Feel Cool TV.app`（应用显示名：`很酷TV`，系统名称：`很酷自在OS 6`，版本：`v6.3.0` / `6.3.0.1020`），双击即可运行。

### 源码构建依赖
- macOS 12.0 及以上
- Rust 工具链 (`cargo`)
- FFmpeg（建议安装于 `/opt/homebrew/bin/ffmpeg` 或 `/usr/local/bin/ffmpeg`）
- 米家 CLI 工具 `mi`（用于开始页实时读取室内温湿度）
- BetterDisplay（可选，用于 `F20` 硬件亮度调节）

```bash
cd src-tauri
cargo tauri dev
```
