# Feel Cool TV (v4.7.0)

基于 Tauri 2、Rust 与 FFmpeg 构建的 macOS 本地与网络媒体播放应用，采用全键盘/遥控器焦点导航，支持本地影视管理、IPTV 直播、抖音与 bilibili 短视频浏览及实时气象提示。

---

## 功能概览

- **界面、导航与多风格交互音效**：支持左侧与顶部两种侧边栏布局，提供 Liquid Glass（深色/浅色）与传统毛玻璃材质选项；支持自动折叠、始终折叠、自动隐藏与始终隐藏方案；丸形菜单、选集列表及正式播放页播放按钮均适配 Liquid Glass 样式；内置空间感交互音效引擎，提供 **“深海流光”**（默认，平滑舒缓无点击感）、**“星云潮汐”**（空灵泛音滑音无点击感）与 **“深邃脉冲”** 三种音效方案，支持在设置页开启/关闭、切换音效方案及按 `20%`–`100%` 调节音量；macOS 顶部系统菜单栏全面汉化，并锁定定制应用图标。
- **正在观看**：按“很酷 TV+”、“有线电视”、“短视频”（及解锁后的“限制级”）分区记录播放历史，各分区独立保存最多 20 条记录，支持断点续播与同剧集多集自动归并；短视频内容大标题显示“作者名 + 的视频”，副标题显示“短视频社区 · 媒体源”。
- **很酷 TV+**：支持剧集与电影双目录扫描，大标题统一显示“很酷 TV+”品牌标识，自动解析季/集编号，抓取并本地缓存 TMDB 元数据、海报、透明 Logo 及豆瓣/TMDB 评分；剧集正式播放页面支持底部选集列表切换。
- **有线电视**：支持 M3U/IPTV 直播源播放、境内/海外源分流、隔行扫描反交错处理及 XMLTV EPG 节目单匹配。
- **短视频**：聚合抖音与 bilibili 多分类视频流，一级丸形菜单默认显示当前对应子分类名（如“抖音精选”、“bilibili 推荐”），二级丸形菜单首项内置等高 Liquid Glass 搜索框（实时过滤标点符号，返回键专注退格不失焦，通过方向键移出搜索框）；主页面卡片大标题显示“作者名 + 的视频”、副标题显示“来自 + 媒体源及分区”；支持抖音与 bilibili 关键词搜索、跨轮刷新去重、卡片序列末尾无感自动续载、过期视频流地址实时续期、bilibili 账户个性化推荐流同步、点赞与收藏状态显示，以及正式播放页面下的“只看作者”多页作品连播模式。
- **低功耗性能调优与辅助功能**：背景视频播放期间自动休眠底层 Canvas 渲染循环、后台隐藏抓取器智能降频与按需轮询；顶部气象预警与降水提示（自动避让顶部侧边栏）、整点/半点时钟显示、正式播放页面暂停态标题跑马灯 10 轮自动停止、BetterDisplay 屏幕亮度联动控制（`F20`）及多级设置面板。

## 快捷键说明

| 按键 | 主页面 / 侧边栏 / 丸形菜单 | 正式播放页面 | 设置页 / 密码页 / 电源页 |
| :--- | :--- | :--- | :--- |
| `↑` / `↓` / `←` / `→` | 移动焦点（搜索框需用方向键移出；卡片末尾向右自动加载更多） | `↓` 上一频道/视频（剧集唤出选集）；`↑` 下一频道/视频；`←`/`→` 快退/快进 | 上下移动焦点；状态项按 `←`/`→` 切换选项 |
| `Return (Enter)` | 进入正式播放页面 / 展开选集或子分类 / 搜索框触发搜索 | 单击暂停/继续；短视频双击点赞、长按收藏 | 进入下一级设置 / 切换状态项 / 确认 |
| `Escape` / `Backspace` | 返回侧边栏或返回“正在观看”（搜索框激活时仅用于退格） | 退出正式播放页面返回主页面（后台继续播放） | 逐级返回或关闭当前覆盖页 |
| `F16`（菜单键） | 唤出 / 收起侧边栏（“始终隐藏”模式下用于唤出侧边栏） | 剧集唤出选集列表 / 短视频唤出选项菜单 / 显隐进度条 | — |
| `F17`（长按替代键） | 触发当前焦点元素的长按操作 | 短视频正式播放页面下触发收藏 / 取消收藏 | 一级设置页显现“限制级内容设置” / 密码页唤出数字键盘 |
| `F18`（主页键） | 存在活动视频流时切入正式播放页面 | 退回主页面并聚焦“正在观看” | 关闭弹窗并回到主页面“正在观看” |
| `F19`（睡眠键） | 暂停播放并进入关机黑屏过渡，随后返回主页面 | 同左 | 同左 |
| `F20`（亮度键） | 唤出底部亮度条，`←`/`→` 按 `±10%` 调节 | 同左 | — |

## 运行与开发

### 直接运行
项目根目录包含已打包的 `Feel Cool TV.app`（`v4.7.0`），双击即可运行。

### 源码构建依赖
- macOS 12.0 及以上
- Rust 工具链 (`cargo`)
- FFmpeg（建议安装于 `/opt/homebrew/bin/ffmpeg` 或 `/usr/local/bin/ffmpeg`）
- BetterDisplay（可选，用于 `F20` 硬件亮度调节）

```bash
cd src-tauri
cargo tauri dev
```
